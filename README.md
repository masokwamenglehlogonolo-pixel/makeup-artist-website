# Maya Rose — Makeup Artist Website

A minimalist, responsive website for a professional makeup artist, featuring:

- Home/hero section
- About section
- Contact booking enquiry form
- Mobile navigation
- Responsive desktop and mobile layouts

## Preview locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
